# PCSX2 GS changes for iOS (GPL-3.0)

`gt4recomp-gs-ios.patch` is this port's change to PCSX2's GS as [vgs499p/gt4recomp-gs](https://github.com/vgs499p/gt4recomp-gs)
has it (commit `ec8eb8b1694cc02bd914629d18baae55e96397df`, PCSX2 v2.8.2 based). `make_ipa.sh` applies it before
building.
